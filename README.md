# Student Information Management System

## Description
A Python-based Student Information Management System that reads and writes student records using a JSON file. It demonstrates nested dictionaries and lists while providing searching, filtering, summary, and data management operations.

## Features
- Load student information from a JSON file using `json.load()`.
- Save student information using `json.dump()`.
- Display all student records.
- Search for a student by name.
- Filter students based on minimum marks.
- Calculate average marks and identify the highest and lowest scorers.
- Add new students with their marks and subjects.
- Handle missing files, invalid JSON, and invalid numeric inputs.

## Technologies Used
- Python 3
- JSON
- Built-in Python functions and data structures

## How to Run
1. Install Python 3.
2. Place `main.py` and `data.json` in the same folder.
3. Open a terminal in that folder.
4. Run the following command:

```bash
python main.py
```
